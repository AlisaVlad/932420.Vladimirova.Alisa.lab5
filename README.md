## Реализованный функционал
1. **Поиск элементов:** Используются `getElementById`, `querySelector`, `querySelectorAll`.
2. **Манипуляции с DOM:**
   - Добавление новых карточек привычек
   - Удаление карточек
   - Изменение текста и атрибутов (прогресс-бар, `aria-valuenow`).
   - Изменение классов (переключение темы, скрытие блока).
3. **Переключение темы:** Кнопка «Сменить тему» переключает светлую и тёмную тему для всего сайта.
4. **Скрытие/показ блоков:** Кнопка скрывает и показывает контейнер с карточками привычек.
5. **Обработка ошибок:** В JavaScript реализована проверка наличия контейнера привычек. Если его нет на странице, скрипт выводит ошибку в консоль и прекращает работу.
6. **Сохранение в LocalStorage:**
   - Сохраняется HTML-структура карточек (вместе с прогрессом).
   - Сохраняется выбранная тема.
   - Сохраняется состояние видимости блока привычек.
   - При загрузке страницы данные восстанавливаются, а обработчики событий перепривязываются к элементам.
